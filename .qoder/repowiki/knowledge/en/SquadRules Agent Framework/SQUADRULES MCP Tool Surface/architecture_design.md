src/tools/ is the single MCP tool boundary: `tool-registry.ts` declares the canonical `SQUADRULES_TOOL_REGISTRY` array that drives MCP `tools/list`, HTTP `/api/<tool>` routes, and CLI commands from one source of truth. Each child module (workflow_engine, export, artifacts) implements one or more registered tools and imports shared helpers — `forward.ts` (MCP→HTTP adapter), `mcp-tool-input-teaching.ts` (teaching-mode input normalization), `next-pow-helpers.ts` / `next-proof-types.ts` (proof-of-work state), `squadrules-uri.ts` (adapter URIs), and `local-artifact-dir-contract.ts` (artifact materialization contract). Cross-child wiring happens via these shared modules rather than direct imports between children; the registry plus `resolveToolDoc` also pulls per-tool descriptions from embedded docs. UI metadata for selected tools comes from `../mcp-apps/squadrules-ui-constants.js`. The `skill-export/` subdirectory is a self-contained artifact-sanitization library used by the export tool but not part of the runtime tool surface.
