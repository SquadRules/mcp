Children compose around a shared runtime contract: `infra_runtime` resolves stdio-vs-http mode and boots the local vector-store/embedding pipeline; `http_api` exposes Express routes, OIDC auth, and the MCP transport; `cli` reuses the same authenticated API client for command-line access; `tools` registers activate/forward/reward/train/tune/delete/export/spaces MCP tools whose schemas are consumed by both the HTTP MCP transport and the CLI; `services` implements the business layer (embedding providers, vector/memory stores, Redis cache, metrics) behind backend-agnostic abstractions used by tools and the HTTP layer; `ui` is the Vite SPA served through the same Express server; `embedded_docs` ships Markdown specs into the app space at boot so agents can discover adapter authoring guides via activate/forward. Cross-child wiring happens in the top-level entry points (`src/index.ts`, `src/cli.ts`) rather than in child modules themselves, keeping each child transport-agnostic.
