Single-page app bootstrapped by `main.tsx`, which mounts a `<StrictMode>` tree wrapping `QueryClientProvider` (TanStack Query), `ThemeProvider` (from `./hooks/useThemePreference`), and the root `App`. `index.html` is the Vite HTML template that pre-applies the user's light/dark/system theme via an inline script before React hydrates. `App.tsx` declares the route tree with `react-router-dom`'s `BrowserRouter` at basename `/ui` and uses `React.lazy` + `Suspense` to code-split every page (`HomePage`, `SquadrulesPage`, `RunsPage`, `ProtocolEditPage`, `RunGuidedPage`, `SkillBundlePage`, `ProtocolDetailPage`, `AccountPage`, `NotFoundPage`) under a shared `Layout` component, keeping the initial chunk under 500 kB. Styling is centralized in `index.css`: it imports Tailwind v4 via `@import "tailwindcss"`, maps design tokens from `./theme/tokens.css` into Tailwind's `@theme inline` namespace, and provides accessibility utilities (skip-link, sr-only, reduced-motion). Type augmentation lives in `vite-env.d.ts`, declaring `VITE_SQUADRULES_VERSION` on `ImportMeta.env` and a default export type for `.svg` assets.
