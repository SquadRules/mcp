Single-page editor composed of a top-level `ProtocolEditPage` orchestrating state via `useProtocol` + local React state, plus four focused child components under `protocol-edit/`: `ProtocolEditImportSection` (markdown file import), `ProtocolEditSpaceSection` (target space selection and optional fork from another adapter URI), `ProtocolEditStepCard` (per-step editor supporting shell/forward/user_input/comment challenge types), and `ProtocolEditPreviewColumn` (live rendered preview). Shared constants (`DEFAULT_STEP`, `CHALLENGE_TYPE_KEYS`, `SOURCE_ADAPTER_URI_RE`) and the Zod schema `markdownSchema` live in `constants.ts`. The page owns all mutable state — `ProtocolFormState` (label, triggers markdown, steps array, completion markdown) — and exposes typed updaters (`setFormField`, `setStep`, `addStep`, `removeStep`) to children. Persistence is split by mode: new protocols POST to `/api/train` (optionally with `source_adapter_uri` for forking), existing ones POST to `/api/tune`; both paths validate against `markdownSchema` before submission and navigate to the resulting protocol/skill route on success. Styling uses Tailwind CSS with CSS custom properties for colors/radius; i18n keys are namespaced under `protocolEdit.*`.
