Flat collection of presentational React components under `src/ui/components/` plus a small `run/` sub-package for the guided contract-challenge flow.
- Layout layer: `Layout.tsx` is the root route shell using `react-router` (`Outlet`, `NavLink`) with an `<aside>` sidebar and main content area; it switches between narrow/wide max-width based on route prefix (`/protocols`, `/runs`).
- Shared primitives: `ChallengeCard`, `CopyButton`, `ErrorAlert`, `RenderedMarkdown`, `RichTextEditor`, `SearchResultsSkeleton`, `SpaceSelect`, `StepFlowGraph`, `SurfaceCard` are stateless or lightly stateful presentational components consumed by higher-level pages.
- Run workflow sub-package (`run/`): `SolutionForm.tsx` renders type-dispatched forms (shell / forward / user_input / comment) driven by `RunContract` from `@/lib/runToolTypes`; `RunGuidedContent.tsx` orchestrates the step-by-step guided experience; `runContractChallenge.ts` is the adapter that invokes the backend run tool. The sub-package depends inward on shared types but not on sibling components.
- Styling uses Tailwind utility classes layered over CSS custom properties (`--color-*`, `--radius-md`, `--layout-*`) defined elsewhere in the app's theme, keeping components theme-agnostic.
- Internationalization goes through `react-i18next`'s `useTranslation()` hook; all user-facing strings are keyed rather than literal.
