The `src/ui/` tree is a Vite-built React SPA whose entry (`main.tsx` → `App.tsx`) composes three layers: (1) top-level route pages in `pages/` (home, protocol detail, not-found) plus feature areas `runs_area` and `protocol_edit_area`; (2) reusable building blocks under `components/`, `hooks/`, and `utils/`; (3) cross-cutting assets from sibling scopes — `shared_assets` (CSS design tokens + English i18n bundle), `shared_libs` (API wrapper, run-tool types, editor extensions), and `shared_hooks` / `shared_components`. Children communicate only through these shared boundaries: pages consume hooks from `hooks/` and components from `components/`, while hooks call the centralized API client in `lib/api.ts` against `src/http/` REST endpoints; there is no direct cross-page state sharing beyond React Query caches and the run-session persistence layer. The app shell owns routing, theme switching (light/dark via CSS custom properties in `theme/`), and i18n initialization, keeping feature areas decoupled.
