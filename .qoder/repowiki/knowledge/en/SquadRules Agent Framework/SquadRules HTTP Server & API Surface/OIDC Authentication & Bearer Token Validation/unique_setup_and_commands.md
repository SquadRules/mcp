Requires environment variables `AUTH_ENABLED`, `KEYCLOAK_URL`/`KEYCLOAK_INTERNAL_URL`, `KEYCLOAK_REALM`, `KEYCLOAK_CLIENT_ID`, `SESSION_SECRET`, `AUTH_CALLBACK_BASE_URL`, `AUTH_TRUSTED_ISSUERS`, `AUTH_ALLOWED_AUDIENCES`, `OIDC_GROUPS_ALLOWLIST`; `AUTH_MODE=oidc_bearer` enables Bearer-only mode. Debug tracing toggled via `AUTH_TRACE=true` or `LOG_LEVEL=trace`.
