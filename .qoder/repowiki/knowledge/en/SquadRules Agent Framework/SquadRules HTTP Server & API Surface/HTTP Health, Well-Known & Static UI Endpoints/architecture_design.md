Three independent `setup*` entry points mounted by the HTTP server:
- `http-health-routes.ts`: `setupHealthRoutes(app, memoryStore)` registers `/health` (probes Qdrant via `MemoryQdrantStore.checkHealth`, Redis via `keyValueStore.isConnected()`, embedding provider with a 2s timeout via `Promise.race`) and `/api` (returns service version + endpoint list; marks `auth_required` when `AUTH_ENABLED`). Dependency health is reported as `qdrant` vs `vectorStore` depending on `isQdrantConfigured`, and cache backend as `redis` vs `memory`.
- `http-well-known.ts`: `setupWellKnown(app)` mounts RFC 9728 Protected Resource Metadata at `/.well-known/oauth-protected-resource` (and path-specific `/mcp` variant), RFC 8414 Authorization Server Metadata at `/.well-known/oauth-authorization-server` and `/.well-known/openid-configuration` by fetching and caching Keycloak's `/.well-known/openid-configuration` (5 min TTL, internal URL rewriting via `rewriteInternalKeycloakUrls`), plus delegates client registration to `setupClientRegistrationProxy`. All handlers emit CORS headers (`Access-Control-Allow-Origin`, `Vary: Origin`, `MCP-Protocol-Version` in allowed headers).
- `http-ui-static.ts`: `setupUiStatic(app)` serves the Vite-built SPA from `dist/ui` (overridable via `SQUADRULES_UI_DIR`), redirects `/` → `/ui`, serves static assets with production `etag`/`lastModified`/`maxAge: 1y`, falls back to `index.html` for SPA routes, and applies a per-route rate limiter (`createRateLimiter({ identifier: 'ui-static' })`). Detects presence of the browse-by-letter chunk by scanning `assets/SquadrulesPage-*.js` for `browseByLetterHint`.

Dependency direction: these files depend on `../config.js`, `../services/*`, `../utils/structured-logger.js`, and sibling `./http-client-registration-proxy.js` / `./http-server-config.js`; they do not import each other, keeping each route group independently mountable.
