The module is organized as a thin runtime shell around per-command submodules under `src/cli/commands/`:
- Entry: `index.ts` is the `#!/usr/bin/env node` bin; it imports `log-sink-prelude.ts` first to force all logs onto stderr (stdout is reserved for data payloads), then auto-injects `serve` when stdin is piped (MCP host mode) and delegates to `createProgram().parseAsync()`.
- Program assembly: `program.ts` builds the Commander root (`squadrules`), wires global options (`--url`, `--timeout`, `--retries`, `--format`, `--reseed`, `--no-browser`) via a `preAction` hook that propagates `--url`/`--no-browser` into `SQUADRULES_API_URL` / `SQUADRULES_NO_BROWSER` env vars, and registers every command submodule (`activate`, `forward`, `trainCli`, `spaces`, `tune`, `delete`, `reward`, `export`, `serve`, `login`, `logout`, `token`).
- Output pipeline: `format.ts` resolves `--format` (auto/pretty/json/text) with precedence flag > `SQUADRULES_FORMAT` env > TTY detection; `output.ts` exposes `emitResult(format, data, view)` which dispatches to JSON, text, or pretty rendering plus an optional `nextCall` hint on stderr; `render.ts` provides one `renderXxxPretty`/`renderXxxText` pair per domain type (activate/forward/reward/tune/delete/spaces/train) using semantic color/table helpers from `render-helpers.ts` (chalk instance created per call so colors are stripped when piped).
- Shared utilities split by concern: `local-target.ts` (dependency-free sentinel `stdio://local`); `download-export-ref.ts` (HTTP download of export refs); `upload-guards.ts` (markdown upload validation — size, binary/sensitive content detection, protocol structure check, API base URL normalization with trusted-host allowlist); `skill-zip-local-write.ts` (ZIP basename sanitization, PK signature check, size cap, disk write); `fetch-error.ts` (undici error decoration, retryability classification, network error wrapping); `auth-error.ts` (`AuthRequiredError` + browser launcher with whitelisted binaries and `BROWSER`/`SQUADRULES_NO_BROWSER` control).
- Dependency direction: commands import from this layer; this layer only depends upward on `../tools/*_schema.js` types and `../services/` / `../utils/` for validation — never the reverse. The `log-sink-prelude` must be imported before any other module to take effect before the shared pino logger singleton is constructed.
