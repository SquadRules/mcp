The CLI is organized as a flat runtime layer plus three command groups that all share one contract: `client-factory.ts` / `api-client.ts` resolve the SquadRules API base URL (via `resolve-api-base.ts`) and obtain bearer/refresh tokens from the OS keyring with file fallback (`config-file.ts`, `keyring.ts`, `oauth-refresh.ts`). Every command imports this ApiClient rather than building its own HTTP stack. Commands are grouped by concern in `commands/` (workflow: activate/forward/reward; auth: login/logout/token; data ops: export/train/tune/delete) and registered through `program.ts`. Transport selection is decoupled via the `ActionBackend` abstraction in `backend/` — `local-backend.ts` drives an embedded store while `http-backend.ts` talks to the remote server, selected at runtime by `resolve-backend.ts`. Output formatting is centralized in `render.ts` / `format.ts`, supporting both human-readable and JSON modes consumed uniformly by every command.
