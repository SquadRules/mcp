Three sibling Commander.js command modules, each exporting a `*Command(program)` factory that registers one top-level command (`activate`, `forward`, `reward`) on the shared `Command` instance. Every command follows the same pipeline: parse arguments/options → resolve a backend via `createBackendFromProgram(program)` from `../backend/resolve-backend.js` → call the corresponding backend method (`backend.activate`, `backend.forward`, `backend.reward`) → render output through `emitResult(resolveOutputFormat(program), response, { pretty, text, nextCall })` from `../output.js` with formatters imported from `../render.js`. Error handling is centralized in `../auth-error.js` via `handleApiApiError(error, !isBrowserDisabled())`. The `reward` command additionally performs local argument validation (outcome enum, numeric score) before invoking the backend, using `writeError` + `process.exit(1)` for user-facing input errors rather than throwing. Dependency direction is strictly inward toward `../backend/*`, `../render.js`, `../output.js`, `../format.js`, and `../auth-error.js`; these commands contain no business logic of their own.
