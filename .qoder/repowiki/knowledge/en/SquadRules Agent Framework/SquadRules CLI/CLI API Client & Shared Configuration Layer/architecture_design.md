Internal layering follows a clear dependency direction: low-level primitives at the bottom, config persistence in the middle, HTTP client on top.

- Low-level helpers: `safe-http-url.ts` (URL normalization/validation), `resolve-api-base.ts` (program flag → env → default resolution), `rewrite-login-url.ts` (adjusts IdP login redirect to current baseUrl).
- Persistence layer: `config-file-internals.ts` parses/writes the XDG-compliant JSON schema (`defaultUrl` + per-environment entries); `config-file-write.ts` exports the write helper; `config-file.ts` orchestrates reading, migrating legacy flat configs, and bridging to the keyring via `KEYCHAIN_TOKEN_PLACEHOLDER` sentinels. `keyring.ts` wraps `@napi-rs/keyring` behind a timeout/degradation latch (`isKeyringAvailable`, `getToken`/`setToken`/`getRefreshToken`/`setRefreshToken`) so a hung macOS Keychain falls back to the file after one timeout.
- Auth flow: `oauth-refresh.ts` discovers OIDC endpoints from `/.well-known/oauth-protected-resource` and performs a refresh_token grant using the hardcoded `SQUADRULES_CLI_CLIENT_ID`; `jwtExpiresInSeconds` proactively renews before expiry.
- HTTP client: `api-client.ts` defines `ApiClient` with a single `request<T>` core that handles retry with exponential backoff, 429 Retry-After handling, proactive token refresh, 401-triggered refresh/login, and browser-based PKCE login via `loginWithBrowser`. Public surface methods (`activate`, `forward`, `train`, `tune`, `trainJson`, `delete`, `spaces`, `reward`, `export`, `downloadExportRef`) map to `/api/*` endpoints typed against tool schemas.
- Resolution entry points: `client-factory.ts` composes `ApiClientOptions` from Commander globals (baseUrl, timeout, retries) shared by HTTP-only auth commands; `config.ts` provides `getCliApiUrlDefault()` / `getApiUrl()` used by non-HTTP commands (e.g. local-target mode).

Dependency direction is strictly upward: api-client → oauth-refresh/safe-http-url/config-file/config; config-file → keyring; nothing in this module imports command implementations except the browser login callback.
