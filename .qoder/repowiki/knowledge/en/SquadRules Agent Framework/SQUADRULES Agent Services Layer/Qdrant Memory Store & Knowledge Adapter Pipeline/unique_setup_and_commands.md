On first use `initializeQdrantStore` auto-creates the Qdrant collection, migrates legacy single-vector layouts to named vectors, adds BM25 sparse-vector config (falling back to a recreate-into-temp-collection migration when `updateCollection(sparse_vectors)` is unsupported), creates full-text payload indexes for `adapter_name_text`, `label_text`, `activation_patterns_text`, `tags_text`, and backfills activation-search vectors.
