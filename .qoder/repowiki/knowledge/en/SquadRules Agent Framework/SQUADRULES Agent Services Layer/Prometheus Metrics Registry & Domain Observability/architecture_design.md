Single flat module built around a shared `@prometheus-io/client` `Registry` singleton exported from `registry.ts`, which applies default labels (`service='squadrules'`, `squadrules_version` from build metadata, `instance` from `INSTANCE_ID`/hostname). Each domain file (`http-metrics.ts`, `agent-metrics.ts`, `embedding-metrics.ts`, `export-metrics.ts`, `anomaly-metrics.ts`, `mcp-metrics.ts`, `memory-metrics.ts`, `qdrant-metrics.ts`, `system-metrics.ts`) imports the registry and declares typed `Counter`/`Histogram`/`Gauge` instances with names prefixed `squadrules_`. There is no internal layering — files are peers. `system-metrics.ts` additionally owns process lifecycle instrumentation (uptime, RSS/heap memory via `process.memoryUsage()`, start time) using a 5-second `setInterval` ticker. `export-metrics.ts` is the only file that exposes helper functions (`hrtimeSecondsSince`, `recordExportMetrics`) consumed by callers outside this module; all other files are pure metric declarations.
