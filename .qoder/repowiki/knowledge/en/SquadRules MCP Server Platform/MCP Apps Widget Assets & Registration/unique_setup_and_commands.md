New widgets are added by creating the three-file triplet plus a `register-*-ui-resources.ts`, registering both URIs against `server.registerResource`, adding `_meta.ui.resourceUri` to the corresponding `registerTool` call in `src/server.ts`, and exporting builders in `list-offering-for-ui.ts`. The `SQUADRULES_MCP_WIDGET_PRESENTATION_ONLY=true` env var disables all postMessage bridge calls for offline HTML/CSS testing.
