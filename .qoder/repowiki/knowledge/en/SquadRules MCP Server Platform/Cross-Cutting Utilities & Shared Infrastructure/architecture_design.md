Flat collection of independent utility modules grouped by concern:
- Logging & auditing: `structured-logger.ts` wraps Pino via a `StructuredLoggerApi`, sanitizes every binding through `sanitizeBindingsForAudit`/`toSafeAuditValue`, and fans out to an optional file sink driven by `AUDIT_LOG_FILE`; `audit-log-events.ts` defines the allowlisted `AuditCategory`/`AuditEventName` union and `buildAuditLine` serializes records.
- Vector storage (Qdrant): `qdrant-utils.ts` is a barrel re-exporting `qdrant-vector-types.ts` (vector descriptors, dimension-aware naming `vs${dim}`, collection alias resolution), `qdrant-collection-utils.ts`, `qdrant-vector-management.ts`, and `qdrant-query-utils.ts` — callers import only from the barrel.
- Multitenancy: `tenant-context.ts` exposes a `SpaceContext` stored in Node `AsyncLocalStorage` (`runWithSpaceContext`, `runWithSpaceContextAsync`, `runHttpApiWithSpaceContext`) derived from Keycloak JWT claims (`sub`, `groups`, `realm`, `iss`) into deterministic `user:`/`group:` IDs; `space-filter.ts` builds Qdrant `must` filters that enforce `allowedSpaceIds` isolation.
- Runtime helpers: `mcp-tool-doc-runtime.ts` resolves embedded markdown docs replacing `{{SQUADRULES_GROUP_SPACE_PATH_EXAMPLE}}` with the deployment-specific path; `uri-builder.ts`, `protocol-slug.ts`, `frontmatter.ts`, `dump-markdown.ts`, `memory-body.ts`, `memory-store-utils.ts`, `normalize-redis-url.ts`, `concurrency-limit.ts`, `protected-space-write-guard.ts`, `resolve-space-param.ts`, `squadrules-*-dirs.ts`, `version-compare.ts`, `build-version.ts`, `global-error-handlers.ts`, `log-core.ts`, `zod-to-jsonschema.ts`, `audit-mcp-summary.ts`, `audit-secret-patterns.ts` provide focused helpers consumed by `src/tools/`, `src/services/`, and `src/http/`.
Dependency direction is one-way: this module imports from `../config.js`, `../services/embedding/config.js`, and `../resources/embedded-mcp-resources.js` but is not imported by services — it is a leaf dependency layer.
