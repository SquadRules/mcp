Flat collection of presentational React components plus a `run/` sub-package that implements the per-contract run workflow. Top-level files are stateless or lightly stateful UI primitives: `Layout.tsx` is the route shell (react-router `Outlet`, sidebar nav, wide/narrow main width), `SurfaceCard.tsx` and `ChallengeCard.tsx` are generic containers, `StepFlowGraph.tsx` renders a linear Start→Steps→Attest pipeline, `RichTextEditor.tsx` wraps Tiptap with a markdown-safe value/onChange contract, and `RenderedMarkdown.tsx` / `ErrorAlert.tsx` / `CopyButton.tsx` / `SearchResultsSkeleton.tsx` / `SpaceSelect.tsx` are small helpers. The `run/` sub-package owns the domain-specific pieces: `SolutionForm.tsx` drives a type-dispatched form over `RunContract` (shell/tensor/mcp/user_input/comment) emitting `RunSolutionSubmission`; `RunGuidedContent.tsx` renders challenge previews; `runContractChallenge.ts` maps a live `RunContract` to `ChallengeCard` props — this file is the only cross-boundary dependency between the two layers. All components consume design tokens via CSS custom properties (`--color-*`, `--radius-*`, `--layout-*`) and i18n via `react-i18next`'s `useTranslation`. No internal routing beyond `Layout`'s `NavLink`s; business types come from `@/lib/runToolTypes`.
