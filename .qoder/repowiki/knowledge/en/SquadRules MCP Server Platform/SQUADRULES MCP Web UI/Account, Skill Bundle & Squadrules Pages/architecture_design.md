Three independent React page components under `src/ui/pages/`, each a leaf of the UI route tree:
- `AccountPage.tsx` renders the signed-in user profile (name, email, groups, identity provider) using `useMe()` from `@/hooks/useAuth`, plus a theme preference dropdown driven by `useThemePreferenceContext`.
- `SkillBundlePage.tsx` reads a protocol via `useProtocol(decodedUri)` from the URL params, lets the user edit description/when-to-use fields through `RichTextEditor`, and exports a downloadable `.zip` via `fetchSkillZipBundle` / `triggerFileDownload` from `@/lib/export-skill-zip`.
- `SquadrulesPage.tsx` is the main entry point: it syncs `q` and `space` query params to local state via `useSearchParams`, calls `useActivate(query, space)` and `useSpaces(includeAdapterTitles)`, sorts activation choices by role then score, and delegates rendering to sub-section components in `@/pages/squadrules-page-sections` (`SquadrulesActivateResultsSection`, `SquadrulesBrowseByLabelSection`).

Dependency direction is one-way: pages consume hooks (`useAuth`, `useProtocol`, `useActivate`, `useSpaces`, `useThemePreferenceContext`) and shared components (`SurfaceCard`, `RichTextEditor`, `SpaceSelect`, `ErrorAlert`, `SearchResultsSkeleton`); they do not expose any module-level API. Styling is uniform Tailwind with CSS custom properties (`--color-*`, `--radius-md`, `--badge-*`) rather than scoped styles.
