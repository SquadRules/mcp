Entry point `main.tsx` mounts a StrictMode tree wrapping `QueryClientProvider`, `ThemeProvider` (from `hooks/useThemePreference`), then `App`. `App.tsx` configures React Router with `basename='/ui'` and declares every page as a `lazy()` import under `<Suspense fallback={<RouteFallback />}>` to keep the initial chunk under 500 kB; all routes are nested under a shared `<Layout>` shell. Pages in `pages/` consume cross-cutting concerns via: hooks from `hooks/` for protocol editor state, auth, spaces, run-session lifecycle, and theme; shared components from `components/` (Layout, ChallengeCard, RichTextEditor, StepFlowGraph, etc.); centralized fetch via `lib/api.ts`; design tokens and light/dark CSS variables from `theme/`; and English translations from `i18n/en.json`. The `run/` subdirectory of `components/` plus `hooks/useRunSession.ts` together implement the agent-first activate→forward→reward flow, while `protocol-edit/` pages compose those same run-view components into an authoring surface.
