Flat collection of independent React hooks under `src/ui/hooks/`, each owning one concern:
- Workflow lifecycle: `useActivate` (GET adapters via `/api/activate`), `useForwardStart` + `useForwardStep` (POST to `/api/forward`), `useReward` (POST to `/api/reward`) — all use `@tanstack/react-query` (`useQuery` / `useMutation`) and call `@/lib/api`.
- Session persistence: `useRunSession.ts` defines `RunSession` / `RunHistoryItem` types from `@/lib/runToolTypes`, persists an array keyed by `squadrules.runSessions.v1` in `localStorage`, normalizes legacy field names (`protocol_uri`→`adapter_uri`, `current_step`→`current_layer`, `challenge`→`contract`, `attest_uri`→`reward_uri`, `ready_to_attest`→`ready_to_reward`) before storing.
- Protocol editor: `useProtocol.ts` fetches markdown via `/api/export` with `format: "markdown"`, then provides pure functions `parseProtocolMarkdown`, `parseProtocolMarkdownToForm`, `buildMarkdownFromForm` that round-trip a Markdown schema with fenced ```json blocks containing `{ contract: { type, ... } }` payloads for shell/mcp/user_input/comment steps.
- Domain data: `useSpaces.ts` lists spaces via `/api/spaces`; `useAuth.ts` wraps `/api/me` as `useMe`.
- UI state: `useThemePreference.tsx` exposes a `ThemeProvider` + `useThemePreferenceContext()` consuming `window.matchMedia("prefers-color-scheme: dark")` and persisting to `squadrules:ui:theme-preference` in localStorage.
Dependency direction is strictly inward: hooks depend on `@/lib/api`, `@/lib/runToolTypes`, and shared component types; nothing in this directory imports sibling components beyond `@/components/ChallengeCard`'s `ChallengePayload` type.
