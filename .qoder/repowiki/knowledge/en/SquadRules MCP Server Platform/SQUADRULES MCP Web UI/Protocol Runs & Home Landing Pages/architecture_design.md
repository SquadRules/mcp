Three sibling React components under `src/ui/pages/` that compose higher-level hooks and shared UI primitives:
- `HomePage.tsx` is a lightweight orientation shell: it queries spaces via `useSpaces`, renders a search form that navigates to `/squadrules`, and exposes three entry cards (Browse → `/squadrules`, Create → `/protocols/new`, Runs → `/runs`).
- `RunsPage.tsx` lists persisted run sessions from `useRunSessions()`, each row linking to a guided run at `/protocols/{adapter_uri}/run?session={id}` and offering resume/remove actions.
- `RunGuidedPage.tsx` is the orchestration hub for the agent-first workflow: it reads the adapter URI from route params and an optional `session` query param, initializes or resumes a `RunSession` via `useRunSession` + `useRunSessions.upsert`, then wires three mutation hooks (`useForwardStart`, `useForwardStep`, `useReward`) to drive the activate→forward→reward lifecycle. It persists intermediate state (status transitions `running` / `ready_to_reward` / `completed` / `error`, history entries, proof hashes) and delegates rendering of the step-by-step UI to `RunGuidedContent`.

Dependency direction is one-way outward: pages depend on `@/hooks/*` (state/mutation), `@/components/*` (SurfaceCard, ErrorAlert, RunGuidedContent, SpaceTypeBadge), and `react-router` for navigation; they do not import business logic directly. The module itself has no internal sub-packages — it is a flat page layer.
