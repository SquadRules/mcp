Layered around a single public facade `MemoryQdrantStore` (store.ts) which owns the `QdrantClient`, collection alias resolution, health checks, and delegates to two internal collaborators: `MemoryQdrantStoreMethods` for CRUD/search and `MemoryQdrantStoreAdapter` for adapter/artifact ingestion.

- Ingestion path: `store-adapter.ts` normalizes docs, parses frontmatter, then dispatches to either `store-adapter-header-handler.ts` (when a header-based protocol is detected) or `store-default-handler.ts` (fallback). Both rely on `adapter-builder.ts` to split H1 sections into layers using fenced contract blocks from `adapter-contract-blocks.ts`, extract activation patterns (`activation-pattern-payload.ts`) and reward signals, and produce `Memory[]` payloads. Artifacts are handled separately via `store-artifact.ts`.
- Persistence path: `store-methods.ts` implements dense+title+activation-pattern prefetches plus BM25 sparse legs fused via RRF through Qdrant's `query()` API; reads go through `redisCacheService` before hitting Qdrant.
- Schema bootstrap: `store-init.ts::initializeQdrantStore` creates/alters collections, migrates old single-vector layouts to named vectors, adds BM25 sparse config (with recreation fallback), creates full-text payload indexes, and backfills activation-search vectors via `activation-search-backfill.ts`.
- Protocol validation: `validate-protocol-structure.ts` enforces required H1/H2 sections and allowed `type` values in contract blocks before training.
- Cross-cutting helpers: `qdrant-point-to-memory.ts` maps Qdrant points to `Memory`, `memory-accessors.ts` reads payload fields, `validate-adapter-markdown-size.ts` caps markdown size, and `store-title-similarity-search.ts` / `store-adapter-helpers.ts` provide title similarity checks.

Dependency direction is one-way outward: this module depends on `../embedding/service.js`, `../redis-cache.js`, `../code-block-processor.js`, and shared `utils/qdrant-utils.js`; nothing inside `src/services/memory/` is imported by other services except through the exported `MemoryQdrantStore` class.
