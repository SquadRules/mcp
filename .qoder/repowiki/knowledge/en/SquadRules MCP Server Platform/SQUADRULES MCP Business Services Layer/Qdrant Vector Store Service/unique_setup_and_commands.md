Collection initialization (`initializeCollection`) auto-creates the collection if missing, recreates it when the vector dimension mismatches the current embedding size, backfills `space_id` for legacy points, and optionally creates a `current` alias — all gated by `QDRANT_URL`/`QDRANT_API_KEY`/`QDRANT_COLLECTION` env vars. When `QDRANT_URL` is unset, importing this module does NOT throw because the exported `qdrantService` singleton is swapped for the embedded store double-cast to `QdrantService`.
