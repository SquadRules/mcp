Two cooperating sub-trees under `src/resources/` plus a constants file:

- Handler bootstrap: `resource-bootstrap.ts` registers a throwaway resource + template then removes them so the MCP SDK installs its `resources/*` method handlers even when no public resources exist; `prompt-resources.ts` does the same for `prompts/list` and `prompts/get` via a placeholder prompt. Both are called once during server init.
- Embedded content serving: `embedded-mcp-resources.ts` is an auto-generated artifact of `scripts/build-embed-docs.ts` that bundles the `src/embed-docs/` tree (prompts, resources, templates, tools, mem, meta) as JS strings keyed by path. `docs-resources.ts` walks this map and calls `server.registerResource` per doc (flat or nested), prefixing URIs with `squadrules://doc`, `squadrules://mem`, etc.; `prompt-resources.ts` walks the `prompts` subtree and calls `server.registerPrompt`. A small `promptOverrides` registry lets callers override title/description/resultDescription per key.
- Shipped adapters bootstrapping: `mem-dir-utils.ts` resolves the `embed-docs/mem` directory (primary dir, then a fallback in sibling `dist`/`src`) and reads `.md` files whose names match `MEM_FILE_SLUG_KEY`. `mem-uuid-mapper.ts` parses frontmatter to extract slug/H1 title and deletes preexisting app-space entries before retraining. `mem-resources-boot.ts::injectMemResourcesAtBoot` orchestrates the flow: read files → optional semver-based skip (`compareSemver` against stored version) → delete old entries → call `memoryStore.storeAdapter` with `forceUpdate: true` → persist `content_sha256` on layers → invalidate Redis cache.
- Constants: `src/constants/builtin-search-meta.ts` declares slugs for the two built-in footer protocols (`refine-search`, `create-new-protocol`), builds their display labels from the embedded meta docs, and exposes `BUILTIN_PROTOCOL_SLUGS` / `memoryIsBuiltinSearchFooterProtocol` used elsewhere to filter activate results.

Dependency direction is one-way outward: this module depends on `services/memory/store.js`, `services/redis-cache.js`, `utils/frontmatter.js`, `utils/version-compare.js`, `tools/skill-export/sha256.js`, and `config.js`; nothing in those packages imports back into `resources/` except the generated `embedded-mcp-resources.ts` which is consumed by both this module and `builtin-search-meta.ts`.
