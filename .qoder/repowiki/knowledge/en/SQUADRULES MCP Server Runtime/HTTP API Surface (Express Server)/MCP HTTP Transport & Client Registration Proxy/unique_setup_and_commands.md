The client registration proxy is disabled unless both `KEYCLOAK_REALM` and `KEYCLOAK_URL` are set — `setupClientRegistrationProxy` returns early otherwise. The MCP handler's concurrency limit comes from `MAX_CONCURRENT_MCP_REQUESTS_RAW` resolved through `resolveMaxConcurrentRequests`. Audit payload depth is controlled by `AUDIT_LOG_LEVEL` (0 = off, 2 = include request args, 3 = include response body).
