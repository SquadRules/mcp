Three sibling Express setup functions — `setupHealthRoutes`, `setupUiStatic`, `setupWellKnown` — each exported from its own file and mounted by the parent HTTP server. Dependency direction is inward: health probes depend on services (`MemoryQdrantStore`, `embeddingService`, `keyValueStore`) plus `config.js`; static UI serves a Vite-built SPA from `dist/ui` with an optional `SQUADRULES_UI_DIR` override; well-known routes implement RFC 9728 Protected Resource Metadata (GET `/ .well-known/oauth-protected-resource[/mcp]`) and proxy RFC 8414 Authorization Server Metadata from Keycloak via `fetchUpstreamAuthServerMetadata` with a 5-minute in-process cache and internal-to-external URL rewriting through `rewriteInternalKeycloakUrls`. The well-known module delegates dynamic client registration to `http-client-registration-proxy.ts` and reuses the shared rate limiter factory from `http-server-config.js`. Cross-cutting concerns (structured logging, config constants, build version) are imported from `../utils` and `../config.js` rather than duplicated.
