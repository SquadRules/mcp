The `http-server.ts` bootstrap registers all route groups from sibling modules: `api_routes` (REST /agent/*), `mcp_server_client` (/mcp/* + client registration proxy), `export_download` (/download/*), and `health_static_wellknown` (/health, /ui, /.well-known). Cross-cutting concerns are centralized in `server_infrastructure`: global middleware (helmet, rate-limits, metrics via `http-metrics-middleware.ts`, error handlers via `http-error-handlers.ts`) is applied once before any route group mounts. Authentication is unified through `auth_oidc`, which provides both browser-session OIDC (PKCE) and Bearer JWT validation; every route group consumes the same `AuthPayload` contract rather than re-implementing auth. The MCP transport layer (`mcp-audit-emit.ts`, `mcp-ui-offerings-auth-jsonrpc.ts`) sits alongside REST routes but uses its own per-request lifecycle with concurrency limits and audit emission, while the REST surface stays stateless and agent-driven.
