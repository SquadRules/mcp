- Each provider implementation (`postEmbeddingsOpenAI`, `postEmbeddingsTEI`, `postEmbeddingsFastEmbed`) follows the same shape: validate config, normalize input to string[], compute `inputCharLength`, wrap calls in a retry loop bounded by `EMBEDDING_MAX_RETRIES` and a wall-clock deadline, emit `auditProviderCall`, then call `setResolvedEmbeddingDimension` and `setSuccessfulProvider` on success.
- Transient network failures are retried using exponential backoff with full jitter (`computeBackoffMs`) and `Retry-After` header precedence capped by `EMBEDDING_RETRY_AFTER_CAP_MS`; non-retriable conditions (401, OpenAI `insufficient_quota`) fail fast without retry.
- Audit logging goes through `structuredLogger` with a `category: 'audit.embedding'` field plus snake_case metadata keys (`tenant_id`, `request_id`, `input_count`, `output_dimension`, `latency_ms`), and request-scoped tenant/request IDs are pulled from `utils/tenant-context` rather than passed as arguments.
- Runtime configuration values are read from the centralized `../../config.js` module; provider-specific URL construction (e.g. appending `/v1/embeddings`) lives in `config.ts` so provider files stay free of URL concatenation logic.
- Heavy or optional dependencies (the `fastembed` SDK) are imported dynamically inside the function that needs them, with a module-scope promise memoized so concurrent callers share one initialization attempt.
