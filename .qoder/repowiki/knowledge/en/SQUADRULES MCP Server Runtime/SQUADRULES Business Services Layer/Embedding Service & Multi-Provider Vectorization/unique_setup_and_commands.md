Startup must call `probeEmbeddingDimension()` before any code that reads `getResolvedEmbeddingDimension()` (e.g. before memory store init); otherwise it throws. Environment variables: `OPENAI_API_KEY`, `OPENAI_EMBEDDING_MODEL`, optional `OPENAI_API_URL` override, `TEI_BASE_URL` + `TEI_MODEL`, `FASTEMBED_MODEL` + `FASTEMBED_CACHE_DIR`, `EMBEDDING_PROVIDER` (`openai` | `tei` | `fastembed` | `auto`), and retry knobs `EMBEDDING_MAX_RETRIES` / `EMBEDDING_RETRY_BASE_DELAY_MS` / `EMBEDDING_RETRY_MAX_DELAY_MS` / `EMBEDDING_RETRY_AFTER_CAP_MS` / `EMBEDDING_RETRY_BUDGET_MS`.
