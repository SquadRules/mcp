Three flat files under src/types/ with no runtime code:
- index.ts defines the shared error class `SquadrulesError` and the quality-metrics schema (`QualityMetrics`, `ImplementationStats`, `ModelImplementationData`, `HealerContributions`, `StepSuccessRate`) used by the scoring/reward pipeline.
- memory.ts declares the core domain shapes: `AdapterInfo`, `InferenceContractDefinition` (with discriminated sub-fields for shell/forward/user_input/comment/subagent), `TensorValue`, `RewardRecord`, `ExecutionTrace`, and the canonical `Memory` record that is persisted as a Qdrant point payload. It imports `ShellInterpreter` from `../tools/shell-challenge-invocation.js`, making this module the single source of truth that both tools and services consume.
- archiver-zip.d.ts is a declaration-only shim that narrows the `archiver` package to only the `ZipArchive` ESM API consumed by `src/tools/skill-export/zip-bundle.ts`, bridging the gap between @types/archiver v7 and the ESM `ZipArchive` export in archiver@8.
Dependency direction is inward: types depend on tool interfaces but are depended on by tools/services/http; there are no circular dependencies within the module itself.
