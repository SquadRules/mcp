Each tool file follows a two-part split: a pure `execute*` function that takes service dependencies (`QdrantService`, `MemoryQdrantStore`) and returns typed results, plus a `register*Tool` factory that wires it to the MCP server with Zod schemas. Input/output contracts live in sibling `*_schema.ts` files using Zod (`delete_schema.ts`, `update_schema.ts`, etc.) and are wrapped by `mcpLooseToolInput` for agent-friendly schema relaxation. URIs are normalized through shared helpers in `squadrules-uri.js` (`parseSquadrulesUri`, `buildLayerUri`, `assertWireAdapterUri`), so delete accepts both `squadrules://adapter/{slug}` and `squadrules://layer/{uuid}`, while update is restricted to canonical layer URIs. The dump tool additionally resolves multi-layer protocols via `resolveAdapterFirstLayer` and `getAdapterLayers`, renders Markdown through `dump-markdown.js` utilities, and caches memory reads through `redisCacheService`. All tools emit OpenTelemetry-style metrics via `mcp-metrics.js` (`mcpToolCalls`, `mcpToolDuration`, `mcpToolErrors`, `mcpToolInputSize`, `mcpToolOutputSize`) and surface tenant context from `tenant-context.js`. Tool registration is centralized in `src/server.ts` which imports each `register*Tool`.
