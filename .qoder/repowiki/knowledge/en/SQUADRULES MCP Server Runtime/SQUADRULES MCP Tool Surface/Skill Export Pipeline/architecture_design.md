The module is a linear assembly pipeline orchestrated by `assemble-skill-item.ts`, which calls the dump service to fetch adapter markdown, normalizes legacy vocabulary (`challenge` → `contract`), derives metadata via `derive-metadata.ts`, renders the final `SKILL.md` through `build-skill-md.ts`, hashes it with `sha256.ts`, scans it for diagnostics via `scan-diagnostics.ts`, and finally packages files (including artifact attachments from `artifact-files.ts`) into a ZIP bundle via `zip-bundle.ts`. The pluggable artifact sanitization rules live in the sibling `artifact-sanitization/` subdirectory and are invoked as part of the file-attachment phase; both the assembler and sanitizer share the `types.ts` contracts (`SkillExportItem`, `SkillExportFile`, `SkillExportDiagnostic`). Cross-cutting concerns — SHA-256 hashing (`sha256.ts`, `sha256sums.ts`), MIME normalization (`artifact-sanitization/normalize-mime.ts`, `extension-mime-map.ts`), and extension/MIME consistency validation (`artifact-sanitization/rules/extension-mime-consistency.ts`) — are factored out so the assembler stays focused on orchestration. Space adapters are enumerated via `enumerate-space-adapters.ts` before the per-adapter loop.
