The module is a pipeline of pure transformation functions centered on the `SkillExportItem` shape in `types.ts` (slug/name/description/squadrulesUri/files/diagnostics). Entry point `assemble-skill-item.ts` orchestrates: dump protocol markdown via `executeDump`, derive frontmatter metadata from `derive-metadata.ts` (parsing YAML frontmatter + H1 title), build the final `SKILL.md` via `build-skill-md.ts`, compute SHA-256 via `sha256.ts`, and scan diagnostics via `scan-diagnostics.ts`. Attached files are loaded by `artifact-files.ts` using `listAdapterArtifacts` and passed through the pluggable `artifact-sanitization/` sub-package, which exposes an `ArtifactSanitizationRule` interface (`id` + pure `evaluate`) and a rule runner (`run-sanitization.ts`). Built-in rules live under `artifact-sanitization/rules/` (e.g. extension-MIME consistency) plus a default factory; the sub-package re-exports only its public surface via `index.ts`. Output bundling is handled by `zip-bundle.ts` (archiver-based streaming to a `Writable` or in-memory buffer) and helper utilities like `enumerate-space-adapters.ts`, `sha256sums.ts`, and `artifact-relative-path` normalization. Dependency direction is one-way: this module depends on `services/memory/store.js`, `services/qdrant/service.js`, and sibling tool modules (`../dump.js`, `../artifact-catalog.js`, `../artifact-relative-path.js`) but is not depended on by services — it is consumed by MCP tool entry points.
