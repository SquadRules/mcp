Pure, stateless rule pipeline centered on the `ArtifactSanitizationRule` interface in `types.ts`, which exposes an `id` and a pure `evaluate(input)` returning zero, one, or many `SkillExportDiagnostic` values. `run-sanitization.ts` is the single orchestrator: it iterates rules in order and flattens their outputs into a cumulative diagnostic list. Concrete rules live under `rules/` (currently only `extension-mime-consistency.ts`), while shared helpers (`normalize-mime.ts`) and the extension→MIME allowlist (`extension-mime-map.ts`) are module-level dependencies. `default-rules.ts` composes the default pipeline by returning the built-in rule set, and `index.ts` re-exports the public surface (`runArtifactSanitization`, `createDefaultArtifactSanitizationRules`, `createExtensionMimeConsistencyRule`, and the `ArtifactSanitizationRule` type). Dependency direction is strictly inward: rules depend on types/helpers; the engine depends only on the rule interface; no I/O occurs inside rules.
