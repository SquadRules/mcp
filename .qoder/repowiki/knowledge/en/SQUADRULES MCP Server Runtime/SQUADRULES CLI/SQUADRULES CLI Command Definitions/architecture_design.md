Each file in this directory exports a single `*Command(program: Command)` function that registers one `squadrules <verb>` subcommand via Commander.js. Commands follow a uniform shape: parse arguments/options, resolve the backend through `createBackendFromProgram` from `../backend/resolve-backend.js`, call a method on the backend (activate / forward / reward / spaces / etc.), then render the response via `emitResult` with pretty/text renderers from `../render.js`. Errors are centralized through `handleApiError` from `../auth-error.js`, which also drives browser-based login on 401. Auth-related commands (`login.ts`, `token.ts`) are self-contained: `login.ts` implements PKCE OAuth against an OIDC server (with a local HTTP callback server), persists tokens via `config-file.js` and optionally the system keyring, and exposes helpers (`getBaseUrl`, `isTokenValid`, `loginWithBrowser`) reused by `token.ts` and other modules. Non-adapter commands (`serve.ts`, `spaces.ts`, `cli-train.ts`, `tune.ts`, `delete.ts`, `export.ts`, `reward.ts`, `forward.ts`, `activate.ts`) delegate all business logic to the backend layer; this module is purely the CLI presentation boundary.
