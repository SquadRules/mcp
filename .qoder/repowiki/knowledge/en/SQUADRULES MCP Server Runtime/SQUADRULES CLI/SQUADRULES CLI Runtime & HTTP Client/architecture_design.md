The module is organized as a thin CLI shell around a single `ApiClient` class:
- Entry: `index.ts` is the `#!/usr/bin/env node` bin that forces stdout/stderr separation via `log-sink-prelude.ts` (sets `SQUADRULES_LOG_STDERR=1` before any logger singleton is created) and auto-injects `serve` when stdin is not a TTY.
- Command registry: `program.ts` builds the Commander tree, reads version from `package.json`, registers global flags (`--url`, `--timeout`, `--retries`, `--format`, `--no-browser`, `--reseed`) and delegates each subcommand to its own `commands/*.ts` file; a `preAction` hook propagates root options into `process.env` for downstream modules.
- Options resolution layer: `client-factory.ts` + `resolve-api-base.ts` + `resolve-timeout.ts` extract `baseUrl`, `timeoutMs`, `maxRetries` from Commander globals with precedence CLI flag > env var > default, kept in leaf modules to avoid cycles with auth/login.
- Core client: `api-client.ts` implements `ApiClient` with a private `request<T>` loop handling timeout (`AbortController`), exponential-backoff retries on transient network errors, 429 `Retry-After` backoff, proactive JWT refresh (singleflighted via `refreshInFlight`), 401-driven browser login flow, and typed endpoints (`activate`, `forward`, `train`, `tune`, `trainJson`, `delete`, `spaces`, `reward`, `export`, `downloadExportRef`).
- Safety/validation helpers: `upload-guards.ts` enforces markdown size/sensitivity/protocol validation and whitelists API base hosts via `SQUADRULES_TRUSTED_API_HOSTS`; `safe-http-url.ts` restricts outbound URLs to http(s) without credentials/query/fragment; `fetch-error.ts` surfaces undici `cause` codes; `local-target.ts` provides the `stdio://local` sentinel shared across config and backend resolution.
- Data-path utilities: `download-export-ref.ts` fetches export payloads, `skill-zip-local-write.ts` validates ZIP magic bytes + size + basename before disk write, `train-batch.ts` walks directories of `.md`+artifacts and emits a batch manifest through the same output formatter.
