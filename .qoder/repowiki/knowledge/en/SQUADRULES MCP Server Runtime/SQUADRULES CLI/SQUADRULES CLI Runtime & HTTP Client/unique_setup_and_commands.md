The bin must be invoked as `squadrules` (or `node src/cli/index.ts`); bare invocation defaults to `serve` only when `stdin.isTTY` is false (MCP host pipe). Stdout is reserved for command payloads — logs always go to stderr because `log-sink-prelude.ts` runs first. Environment variables controlling behavior include `SQUADRULES_API_URL`, `SQUADRULES_TIMEOUT_MS`, `SQUADRULES_RETRIES`, `SQUADRULES_FORMAT`, `SQUADRULES_NO_BROWSER`, `SQUADRULES_TRUSTED_API_HOSTS`, `SQUADRULES_CLI_MAX_MARKDOWN_BYTES`, `SQUADRULES_ALLOW_SENSITIVE_UPLOADS`, and `SQUADRULES_EXPORT_ZIP_MAX_DOWNLOAD_BYTES`.
