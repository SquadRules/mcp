- Configuration values are resolved through dedicated `resolve*` functions (`resolveTimeoutMs`, `resolveMaxRetries`, `getResolvedApiBaseFromProgram`) that read from Commander globals then fall back to `SQUADRULES_*` env vars, keeping precedence uniform across the CLI.
- User-supplied strings entering the filesystem or network are funneled through guard helpers (`normalizeAndValidateApiBaseUrl`, `tryNormalizeHttpUrlForFetch`, `safeZipBasenameFromRemoteHint`, `assertSkillZipBufferAllowedForDiskWrite`) rather than used directly at call sites.
- Network I/O goes exclusively through `ApiClient.request`, which centralizes timeout, retry, 429 backoff, 401 refresh/login, and error wrapping — individual endpoint methods never call `fetch` themselves.
- Sensitive upload content is rejected by default and requires an explicit opt-in via `SQUADRULES_ALLOW_SENSITIVE_UPLOADS=true` or per-call `allowSensitiveUpload` flag, checked against regex patterns for private keys, bearer tokens, Slack bot tokens, and GitHub tokens.
- CLI log output is isolated from payload output by forcing `SQUADRULES_LOG_STDERR=1` in a prelude import that runs before any logger singleton is constructed, preserving stdout as the data channel.
